# ✨ QuaGenius (v1.10) - AI過去問ジェネレーター

『QuaGenius』は、AIのパワーを最大限に活用し、資格試験対策用の良質な過去問を動的に自動生成する高精度な過去問ジェネレーターです。
現在、**「中小企業診断士」**、**「FP1級 (学科)」**、**「税理士」**、**「ITパスポート」**、および**「宅地建物取引士」**の5つの超人気・超難関国家資格に対応しています。

ガラスモーフィズムを採用したプレミアムなダークテーマデザインと、学習効率を限界まで高める数々の先進機能を備えた、受験生のためのモダンな学習SPA（シングルページアプリケーション）です。

---

## 🌟 主要機能と特徴

### 1. 5大国家資格 & 主要科目にフル対応
選択した試験と分野（科目）に合わせて、本試験の過去問傾向に沿った実践的な4択問題をAIが動的に作成します。
*   **ITパスポート**: ストラテジ系、マネジメント系、テクノロジ系
*   **宅地建物取引士**: 権利関係、宅建業法、法令上の制限、税・その他
*   **税理士**: 簿記論、財務諸表論、所得税法、法人税法、相続税法、消費税法
*   **中小企業診断士**: 企業経営理論、財務・会計、運営管理、経済学・経済政策、経営情報システム、経営法務、中小企業経営・中小企業政策
*   **FP1級 (学科)**: ライフプランニングと資金計画、リスク管理、金融資産運用、タックスプランニング、不動産、相続・事業承継

### 2. 解説の音声読み上げ機能 (TTS: Text-to-Speech)
*   Web Speech APIを搭載し、解説テキストを自然な日本語で自動で読み上げます。
*   「聞き流し」による耳からの記憶定着を強力にサポート。
*   問題切り替えやスキップ時には、音声が自動的に停止する安全設計です。

### 3. PDFエクスポート / 印刷機能
*   印刷専用CSS（`@media print`）を細部までチューニング。
*   「PDFとして保存 / 印刷」ボタンをクリックするだけで、余計なボタンや設定フォームを一切排除し、**問題・正答・Markdownによる解説文のみ**を白背景・黒文字で美しくA4等の用紙にレイアウトします。

### 4. 学習時間の視覚的トラッキング (CSS製進捗グラフ)
*   学習セッション中の学習時間（分・秒）をリアルタイムに自動計測。
*   直近7日間の学習状況を、美しくレスポンシブな**棒グラフ（CSS製グラデーション）**でビジュアル化。
*   グラフ上のバーにホバーすると、その日に「何問解いたか」がツールチップでポップアップ表示されます。

### 5. 弱点克服のための「消化型復習モード」
*   間違えた問題は自動的に「間違えた問題ストック」に累積保存。
*   復習モードでランダムに出題され、**正解できた問題のみストックから自動的に削除（消化）**されます。
*   苦手な問題が手元に残り続けるため、効率的な弱点補強が可能です。

### 6. 超快適なバックグラウンド「先読み」UX
*   回答を行った瞬間に、裏で非同期に「次の問題」を生成し始めるため、次の問題へ進む際の**ローディング時間がほぼゼロ（ミリ秒単位）**で瞬時に切り替わります。

## 🛠 技術スタック

*   **HTML5 / CSS3**: カスタム変数、CSS Grid/Flexbox、ガラスモーフィズム (`backdrop-filter`)、印刷専用CSS、ダークモード最適化。
*   **Vanilla JavaScript (ES6+)**: 外部フレームワークに依存しない超高速ロード、Fetch APIによるセキュアな非同期通信、Web Speech API。
*   **Marked.js**: Markdown解説文の高速パース（CDN経由）。
*   **ローカルストレージ (LocalStorage)**: 統計データ、復習問題ストック、APIキーなどの完全なフロントエンド完結型保存。
*   **AIエンジン**:
    *   `Google Gemini 2.5 Flash` (無料枠で高速・高品質に利用可能)
    *   `OpenAI GPT-4o-mini` (有料APIキー向け)
    *   APIエラーやレートリミットを考慮した「3秒待機・最大2回自動リトライ」アルゴリズム搭載。

## 🚀 使い方 (クイックスタート)

1.  本リポジトリをクローンまたはダウンロードし、`index.html` をブラウザで開きます。
2.  画面右上の設定アイコン（⚙️）をクリックし、使用したいAIエンジンのAPIキー（Google Gemini APIキーは [Google AI Studio](https://aistudio.google.com/app/apikey) から無料で取得可能）を入力して保存します。
3.  資格試験、出題分野を選択し、「新規問題を生成」をクリックして学習を開始してください！
