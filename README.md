# ✨ QuaGenius (v2.0.1) - AI過去問ジェネレーター & AI家庭教師

『QuaGenius』は、AIのパワーを最大限に活用し、資格試験対策用の良質な過去問を動的に自動生成し、その場でAI専門講師に深掘り質問までできる次世代の学習プラットフォームです。
現在、**「中小企業診断士」**、**「FP1級 (学科)」**、**「税理士」**、**「日商簿記2級」**、**「日商簿記1級」**、**「ITパスポート」**、および**「宅地建物取引士」**の7つの人気・難関資格に対応しています。

ガラスモーフィズムを採用したプレミアムなダークテーマデザインと、学習効率を限界まで高める数々の先進機能を備えた、受験生のためのモダンな学習SPA（シングルページアプリケーション）です。

---

## 🌟 主要機能と特徴

### 1. 7大資格試験 & 4択・記述ハイブリッド出題にフル対応
選択した試験と分野（科目）に合わせて、本試験の過去問傾向に沿った実践的な4択問題および記述・数値入力問題（仕訳カードやMarkdown試算表を含む）をAIが動的に作成します。
*   **日商簿記2級 / 1級**: 商業簿記・会計学・工業簿記・原価計算（仕訳カード表示・表組み試算表・金額入力対応）
*   **ITパスポート**: ストラテジ系、マネジメント系、テクノロジ系（完全4択ガード対応）
*   **宅地建物取引士**: 権利関係、宅建業法、法令上の制限、税・その他（完全4択ガード対応）
*   **税理士**: 簿記論、財務諸表論、所得税法、法人税法、相続税法、消費税法
*   **中小企業診断士**: 企業経営理論、財務・会計、運営管理、経済学・経済政策、経営情報システム、経営法務、中小企業経営・中小企業政策
*   **FP1級 (学科)**: ライフプランニングと資金計画、リスク管理、金融資産運用、タックスプランニング、不動産、相続・事業承継（基礎編4択・応用編記述計算対応）

### 2. 解説の音声読み上げ機能 (TTS: Text-to-Speech)
*   Web Speech APIを搭載し、解説テキストを自然な日本語で自動で読み上げます。
*   「聞き流し」による耳からの記憶定着を強力にサポート。
*   問題切り替えやスキップ時には、音声が自動的に停止する安全設計です。

### 3. PDFエクスポート / 印刷機能
*   印刷専用CSS（`@media print`）を細部までチューニング。
*   「PDFとして保存 / 印刷」ボタンをクリックするだけで、余計なボタンや設定フォームを一切排除し、**問題・正答・Markdownによる解説文のみ**を白背景・黒文字で美しくA4等の用紙にレイアウトします。

### 4. 学習時間の視覚的トラッキング (CSS製進捗グラフ)
*   学習セッション中の学習時間（分・秒）をリアルタイムに自動計測。
*   直近7日間の学習状況を、美しくレスポンシブな**棒グラフ（CSS製グラデーション）**でビジュアル化。
*   グラフ上のバーにホバーすると、その日に「何問解いたか」がツールチップでポップアップ表示されます。

### 5. 弱点克服のための「消化型復習モード」
*   間違えた問題は自動的に「間違えた問題ストック」に累積保存。
*   復習モードでランダムに出題され、**正解できた問題のみストックから自動的に削除（消化）**されます。
*   苦手な問題が手元に残り続けるため、効率的な弱点補強が可能です。

### 6. 超快適なバックグラウンド「先読み」UX
*   回答を行った瞬間に、裏で非同期に「次の問題」を生成し始めるため、次の問題へ進む際の**ローディング時間がほぼゼロ（ミリ秒単位）**で瞬時に切り替わります。

### 7. 🎓 AI専門講師への深掘り質問（AI家庭教師チャット）[v2.00 新機能]
*   解説を読んだ後に生じる「なぜこの計算式になるのか？」「他の選択肢がダメな理由は？」といった疑問を、その場でAI講師に対話形式で質問できます。
*   「💡初学者向けに噛み砕いて」「🔍他の選択肢・ひっかけの理由」「📐計算・仕訳の手順を1ステップずつ」「📘関連知識・暗記のポイント」の4つのワンタップ質問チップを搭載。

### 8. 🌐 Google検索グラウンディング連動 ＆ 📐 Structured Outputs [v2.00 新機能]
*   Gemini選択時に「最新法改正・Web検索連動」をONにすると、`google_search` ツールを用いて最新の税制改正・法改正・会計基準をWeb検索しながら作問・解説し、参照元リンクを提示します。
*   通常出題時は `responseSchema` による厳格なJSONスキーマ指定（Structured Outputs）を適用し、出力構造エラーを徹底排除しています。

## 🛠 技術スタック

*   **HTML5 / CSS3**: カスタム変数、CSS Grid/Flexbox、ガラスモーフィズム (`backdrop-filter`)、印刷専用CSS、ダークモード最適化。
*   **Vanilla JavaScript (ES6+)**: 外部フレームワークに依存しない超高速ロード、Fetch APIによるセキュアな非同期通信、Web Speech API。
*   **Marked.js**: Markdown解説文の高速パース（CDN経由）。
*   **ローカルストレージ (LocalStorage)**: 統計データ、復習問題ストック、APIキーなどの完全なフロントエンド完結型保存。
*   **AIエンジン（マルチモデル・自動フォールバック搭載）**:
    *   `Google Gemini` (`gemini-2.5-flash` / `gemini-2.5-flash-lite` / `gemini-2.0-flash`) — 無料枠あり・推奨
    *   `Groq` (`llama-3.3-70b-versatile` / `llama-4-scout-17b-16e-instruct` / `llama-3.1-8b-instant`) — 無料枠あり・超高速LPU推論
    *   `OpenRouter` (`openrouter/free` 自動ルーター / `llama-3.3-70b` / `deepseek-chat` / `qwen-2.5-72b`) — 無料枠あり
    *   `OpenAI` (`gpt-4.1-mini` / `gpt-4o-mini`) — 有料APIキー向け
    *   レートリミット(429)、サーバー一時過負荷(503)、スリープ復帰時の通信瞬断、JSON出力崩れに対する自動リトライ＆モデル自動切り替え機構を搭載。

## 🚀 使い方 (クイックスタート)

1.  本リポジトリをクローンまたはダウンロードし、`index.html` をブラウザで開きます。
2.  画面右上の設定アイコン（⚙️）をクリックし、使用したいAIエンジンのAPIキー（Google Gemini APIキーは [Google AI Studio](https://aistudio.google.com/app/apikey) から無料で取得可能）を入力して保存します。
3.  資格試験、出題分野を選択し、「新規問題を生成」をクリックして学習を開始してください！
